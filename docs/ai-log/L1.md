# L1 — Parameters

## Prompt

Run task L1 of `IMPLEMENTATION.md`: `LinkConfig` with its defaults and validation, and tests for
the defaults and the invalid configurations.

## Summary

- **Code**: `crates/igs-iso9506-mms-link/src/config.rs`.
  - `LinkConfig`: the six selectors, the AP-title, the TPDU size, two timeouts, the outstanding
    limits each way, and the nesting level.
  - `LinkConfig::default()` is valid; `LinkConfig::validate()` returns the first refused value as
    a `ConfigError` with its field name.
- **Decisions**: D-015 in `PROVENANCE.md`. It records the bounds, the defaults and their reasons.
  - The TPDU size is 8192 octets, the value the bench reference client proposes (task F5).
  - The selectors are omitted by default. This is to be checked against the reference peer in L6.
  - The nesting level is 2, the TASE.2 minimum. The outstanding limit and the timeouts have no
    clause; they are operational choices.
- **Sources read**: the clauses of X.224, X.225, X.226, X.227 and X.690 that bound each value; the
  TASE.2 stack requirements of 6-702; the types of ISO 9506-2 §8.2; RFC 1006 and RFC 2126 on the
  web for the TCP port and the default TPDU size. Nothing of these texts is stored in the repository.
- **Tests**: `crates/igs-iso9506-mms-link/tests/config.rs`, 14 tests. The defaults, each bound at its
  edge, each refused value, and the messages of the errors.
- **Gate**: `porte=1`. `cargo deny` reports one unused licence allowance (ISC in `deny.toml`), as a
  warning; it was there before this task.
