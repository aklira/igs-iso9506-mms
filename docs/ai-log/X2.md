# X2 — Documentation and examples

## Prompt

Run task X2 of `IMPLEMENTATION.md`: rustdoc on every public item, `examples/`, a README quick start, and a
`CHANGELOG.md`. Done when `cargo doc --no-deps` has no warnings, and the examples compile in CI. Depends on T2
and S2.

## Summary

- **Rustdoc**: every public item of the three library crates is documented (each crate denies `missing_docs`).
  `cargo doc --workspace --no-deps --all-features` has no warning, with `RUSTDOCFLAGS="-D warnings"` as in CI.
  The crate overview of `igs-iso9506-mms` gives the quick start.
- **Examples** (`crates/igs-iso9506-mms/examples/`):
  - `loopback`: a server and a client in one process, over TCP on the loopback: identify, read, write, close.
    It needs no network and no certificate. Run in CI.
  - `client`: identifies a server at an address and lists its domains.
  - `server`: serves a VMD with one domain and one floating-point variable, until stopped.
  - `tls`: a secured server and a secured client in one process, with the PEM files of the two ends.
- **README**: the quick start, the command lines, the crates, the tests, the documents.
- **CHANGELOG.md**: the Unreleased section, with the known gaps.
- **CI**: `.github/workflows/ci.yml` builds the examples (`cargo build --workspace --examples --all-features`) and
  runs the loopback example, in addition to the tests that already build them.
- **Gate**: recorded with the commit.

## Checks run

- `cargo run -p igs-iso9506-mms --example loopback`: exit 0. The output is the identity, the read value, the write,
  and `done`.
- `client` against `server` over TCP (127.0.0.1:10102): the vendor, the model, the revision and the domain
  `plant` are printed by the client.
- `tls` with the test material of `tests/fixtures/tls`: the secured identify succeeds.
- `cargo clippy --all-targets -- -D warnings`: the examples pass the workspace lints (no unwrap, no indexing).

## Note

The examples are not run by `cargo test`; they are built by it, and the loopback one is run by the CI step. The
`client`/`server` pair was checked by hand, as the `server` example needs a terminal to stop.
