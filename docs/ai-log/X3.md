# X3 — Supported service matrix

## Prompt

Run task X3 of `IMPLEMENTATION.md`: `docs/capabilities.md` with the services, the CBBs, the test covering each
row, and the known gaps. Done when every row names a test that exists. Depends on T4 and S4.

## Summary

- **Matrix**: `docs/capabilities.md`, the section "Supported services and CBBs", between the markers
  `<!-- matrix:begin -->` and `<!-- matrix:end -->`. It has one row per service of the profile (Identify,
  GetNameList, Read, Write, GetVariableAccessAttributes, DefineNamedVariableList,
  GetNamedVariableListAttributes, DeleteNamedVariableList, InformationReport), the negotiation and refusal,
  conclusion and abort, the Reject, the cancel, and TLS. Each row gives the client test, the server test, the
  bench test, and the gap.
- **CBB table**: the four parameter CBBs that the server serves (`str1`, `str2`, `vnam`, `vlis`) with the test that
  covers each, and the CBBs it refuses (`vadr`, `valt`, `vsca`, the others) with the test of their refusal.
- **Index of the gaps**: G1 to G19, each with its status and the section that describes it.
- **Checker**: `crates/igs-iso9506-mms/tests/capabilities_matrix.rs`. It reads the section between the markers, takes
  the code spans that contain an underscore (the names of tests), and fails if one is not a `fn` of the crates or a
  `def` of the bench tests. It reads the repository only, so it runs in CI, where `docs/spec` is absent.
- **Check of the checker**: one name in the matrix was changed to a name that does not exist. The check failed,
  and named it. The file was then restored and the check passed.
- **Gate**: `porte=1` (fmt, clippy, doc, test, msrv 1.85, deny, codegen --check).

## Choices

- A name counts as a test when it is a code span with an underscore. Service names (`Read`) and CBBs (`vnam`) have
  none, so they are not checked as tests.
- Gaps keep their numbers from the earlier tasks, so that the logs and the commits still refer to them.
- Nothing is claimed beyond the tests: a row without a bench test says so ("none: the reference tool has no write").

## Reading

ISO 9506-2 §7 (services), §8 (CBBs), §6 (Reject), and IEC 62351-3 (TLS). No standard text is in the document.
