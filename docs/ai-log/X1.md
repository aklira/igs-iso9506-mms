# X1 — TLS (IEC 62351-3)

## Prompt

Run task X1 of `IMPLEMENTATION.md`: a `TlsBackend` trait and a rustls backend, reusing the design of
`igs-iec104`. Application security of IEC 62351-4 is out of scope. Done when the loopback TLS tests for the
client and the server pass. Depends on T1.

## Summary

- **Code**: `crates/igs-iso9506-mms/src/tls/` (`mod.rs` the trait, the stream and the connector;
  `settings.rs` the identity, the trust anchors and the CRLs from PEM; `rustls_backend.rs` the backend).
  `ServerConfig::with_tls` in `server/mod.rs`: each connection runs its handshake before its association.
  `Error::Tls` in `error.rs`.
- **Tests**: `crates/igs-iso9506-mms/tests/tls.rs`, ten tests over real sockets: the TLS 1.3 negotiation and
  MMS over it (identify, read); a TLS 1.2 client; the refusals of a missing certificate, an unknown root, an
  expired certificate, a revoked certificate, a server name outside the certificate, a plain client; the
  backend without a CRL; the station without its own certificate. Their results are in `docs/capabilities.md`.
- **Material**: `tests/fixtures/tls/generate.sh` (openssl), and the certificates and leaf keys it writes. The
  roots' keys are discarded. Test-only.
- **Decisions**: D-030.
- **Gaps**: G16 (the security events of Annex A), G17 (two mandatory TLS 1.2 suites and the CCM suite of TLS 1.3
  are not offered by rustls), G18 (no TLS 1.2 renegotiation), G19 (the 8 192-octet size boundary not tested).
- **Gate**: `porte=1` (fmt, clippy, doc, test, msrv 1.85, deny, codegen --check).

## The refusals, as the peers see them

The alerts and errors of the five negative tests, from the probe run before the assertions were fixed:

```
no certificate:    Io(InvalidData, AlertReceived(CertificateRequired))
unknown root:      Io(InvalidData, AlertReceived(UnknownCA))
expired:           Io(InvalidData, AlertReceived(CertificateExpired))
revoked:           Io(InvalidData, AlertReceived(CertificateRevoked))
server name:       Tls(Handshake("certificate not valid for name \"other.example\"; ...DnsName(\"localhost\") or IpAddress(127.0.0.1)"))
```

The negative tests therefore fail for the intended reason. The probe was removed.

IEC 62351-3 clauses 6.4.1 to 6.4.4.5 (certificates, revocation, expiry), 7.2 (TLS 1.2 suites), 8.2 (TLS 1.3
suites), 10.3 (versions). The design of `igs-iec104`'s X1 log. No standard text is in the code or the docs.
