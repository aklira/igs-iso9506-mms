# N3 — Typed UtcTime, MMSString and TypeDescription (task of igs-iec61850-mms)

## Prompt

Run task N3 of `~/Dev/igs-iec61850-mms/IMPLEMENTATION.md` in this repository.

## Summary

- `mms::utc`: the eight-octet UtcTime read as `UtcTimestamp` (seconds, 24-bit fraction, `TimeQuality` of Table
  36). Invalid accuracies (25 to 30) and wrong lengths are refused. VMD conformance for `UtcTime`.
- `Tagging::Either` for the `mMSString` of `TypeDescription` (generator: `EITHER_TAGGING`). The decoder reads
  both forms; the writer writes the form that the profile asks (`Profile::implicit_mms_string`, true for IEC
  61850, false for TASE.2), through `mms::encode_for`, which the association uses for every PDU.
- `DataMMSString`: UTF-8, 255 characters, at most 1020 octets; malformed UTF-8 refused by the codec.
- Decision D-034, with the trade-off that the decoder reads both forms under every profile.
