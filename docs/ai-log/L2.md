# L2 — COTP connection

## Prompt

Run task L2 of `IMPLEMENTATION.md`: a sans-I/O class 0 connection, `handle(event, now) -> actions`,
with TPDU size negotiation, segmentation and reassembly of bounded size, and deterministic
fake-clock tests for both roles.

## Summary

- **Code**: `crates/igs-iso9506-mms-link/src/transport.rs`.
  - `Connection::new(role, config)` validates the L1 configuration.
  - `Connection::handle(event, now)` takes `Connect`, `Received`, `Send`, `Release` or `Tick`, and
    returns `Transmit`, `Deliver`, `Opened`, `Closed(cause)` or `Misuse`.
  - Input is a TPKT stream: the codec's `FrameDecoder` cuts it into TPDUs whatever the pieces.
- **Negotiation**: the responder answers at the smaller of the proposed size and its own maximum;
  the initiator accepts a CC that does not exceed its proposal. A DR refuses a CR that is not class
  0, with options, credit or user data, or whose called selector is not the configured one.
- **Segmentation and reassembly**: a TSDU is cut to the agreed size minus the three octets of a DT
  TPDU. The reassembled TSDU is bounded by `MAX_TSDU` (1 048 576 octets).
- **Errors**: an ER TPDU quotes the TPDU up to the octet in fault. A broken TPKT stream is closed
  without a reply.
- **Decisions**: D-015 (corrected: the size 8192 is not allowed in class 0 by X.224, and RFC 1006 and
  RFC 2126 allow it) and D-016 (establishment, data transfer, release and errors).
- **Tests**: `tests/transport.rs`, 23 tests on a fake clock; `tests/config.rs` gains the header
  check of the connection request (15 tests).
- **Gate**: `porte=1`. The same `cargo deny` warning on the unused ISC allowance as in L1.
