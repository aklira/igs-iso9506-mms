# T1 — Transport

## Prompt

Run task T1 of `IMPLEMENTATION.md`: an async driver over `tokio::net::TcpStream`, generic over a
stream trait so that TLS plugs in later; a clean shutdown; error types. Done when the tests run
against an in-process loopback, with `tokio::time::pause`.

## Summary

- **Code**: `crates/igs-iso9506-mms/src/`.
  - `transport.rs`: the driver task runs `link::transport::Connection` (L2) on a `ByteStream`. The
    handle `Transport` exchanges TSDUs over bounded channels. `connect`, `accept` and `connect_tcp`.
  - `error.rs`: `Error` (I/O, configuration, connect timeout, transport closed with its cause, peer
    closed, driver stopped, misuse).
  - `lib.rs`: the public names.
- **Decisions**: D-020 (driver, back-pressure, shutdown, timers, dependency `tokio`).
- **Tests**: `tests/loopback.rs`, 11 tests over an in-memory duplex stream, the connect timeout on the
  paused clock.
- **Gate**: `porte=1`. `cargo deny` reports the same unused ISC allowance as before.
- **Not in T1**: the connection to a real peer over TCP (the bench, task T4); the MMS layers over the
  transport (task T2, which also chooses the reconnect policy).
