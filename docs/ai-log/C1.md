# C1 — BER

## Prompt

Run task C1 of `IMPLEMENTATION.md`.

## Summary

Added `igs_iso9506_mms_codec::ber`. It contains:

- `Identifier`, with the universal tags that the modules use.
- `Reader` and `Element`, for identifier, length and contents octets.
- Decoders of the primitive types: BOOLEAN, INTEGER (`i64`, `u64` or the raw octets), ENUMERATED,
  NULL, BIT STRING, OCTET STRING, OBJECT IDENTIFIER and the character strings.
- `Writer`, for primitive and constructed encodings.
- A typed `Error`, whose variants name the X.690 clause they enforce.

The choices of what to accept and write are recorded as D-007.

**Nesting**: the indefinite form is walked without recursion, so 100,000 nested levels are refused
with `DepthExceeded` on a 256 KiB stack. Entering a constructed element counts one level. REAL is
not implemented: no type of the modules uses it.

**Tests**: `tests/ber.rs` has 20 tests with hand-written vectors for each type and one for each
malformed form: tag numbers, lengths, end-of-contents, integers, bit strings, object identifiers
and characters. The bit string vectors in primitive and segmented form follow the example of
X.690 §8.6.4.2.

A throwaway noise run, not committed, read 1 million random inputs in a debug build with overflow
checks on: no panic. Property tests and fuzzing come with tasks C8 and C9.

One test vector was wrong at first: a BOOLEAN without its length octet. The reader refused it,
rightly, with `ReservedLength`, and the vector was fixed.
