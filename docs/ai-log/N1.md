## Summary

`cargo xtask codegen` reads the `variante_61850` modules (ISO 9506 with IEC 61850-8-1 Annex F applied):
the codec gains `Data::UtcTime`, `TypeDescription::UtcTime`, identifiers of 1 to 64 characters, the
`pdu-size` service error and a UTF-8 `DataMMSString`. Decision D-032.

To keep the ISO 9506 profile of TASE.2 unchanged, the generator emits `walk_strings` on every type that
can hold an identifier or the MMS string of `Data`; `mms::check_strings` applies `StringLimits`, and the
association runs it after the CBB check, with the ISO 9506 limits by default (`set_string_limits`). The
`mMSString` of `TypeDescription` keeps its ISO explicit tagging until N3 (`ISO_TAGGING` in the generator);
`DataMMSString` is in `UNCHECKED`, its 255 being a profile limit.

Breaking change of the public API (new alternatives, `Data::MMSString(DataMMSString)`): the next release
is 2.0.0 (CHANGELOG). `igs-iec-tase2` needed one match arm, committed there.

Tests: `tests/string_limits.rs` (new), `tests/common_types.rs`, `tests/mms_pdus.rs` (the UTC time of the
bench peer is now typed), `tests/generated.rs` (145 types, last Data tag 17), and an association unit test.
Standard gate green, minimum Rust version green, `codegen --check` green; `igs-iec-tase2` gate green.
