## Summary

- The refusal of alternate access happens at the CBB check: the server does not negotiate `valt`, so the
  request never reaches the model. `ServerConfig::with_alternate_access()` negotiates it (opt-in).
- `server::access::steps`: an alternate access as a path of `AccessStep`s, from the items of the list, with
  the bounds checked (`PathError`: empty range, range past 32 bits, index out of range). A refused path fails
  its item with `OBJECT_VALUE_INVALID`.
- The generic VMD (`Vmd::dispatch`) is unchanged: it refuses every alternate access item.
- Decision D-035.
