# L4 — Association and Initiate

## Prompt

Run task L4 of `IMPLEMENTATION.md`: the ACSE association carrying the Initiate, the negotiation of
the parameters and of the CBBs, the Conclude and the Abort, and tests for each negotiation result
and for a refused association.

## Summary

- **Code**:
  - `crates/igs-iso9506-mms-link/src/association.rs`: `Association` over the presentation connection;
    `negotiate`, the Initiate negotiation (ISO 9506-1 §8.2.1); the AARQ, AARE, RLRQ and RLRE built
    and read with the codec's ACSE module.
  - `crates/igs-iso9506-mms-link/src/upper.rs` (task L3) gains the user data of the CP, CPA and CPR,
    and the data transfer; its DATA TRANSFER is no longer refused.
- **Behaviour**:
  - The initiator proposes version 4, its outstanding limits and nesting, and its CBBs and services.
  - The responder indicates the request. The user accepts, and the negotiation reduces each value
    to what both ends allow; a refusal carries an AARE and, for a failed negotiation, an
    Initiate-ErrorPDU.
  - Data: requests and responses are checked against the negotiated services before they are sent,
    and on receipt, where an unsupported one is passed up for a Reject PDU.
  - Conclude follows Annex A: CONCLUDE request, RLRQ, the CONCLUDE response and the RLRE, then the
    session release. Abort is the presentation abort with no PDU.
- **Decisions**: D-018. D-017 is updated: the data transfer is now supported.
- **Known gaps**: the TASE.2 services and CBBs are chosen with the client and server tasks; the
  version-dependent PDUs are not checked; the Conclude-ErrorPDU path is not implemented.
- **Tests**: `tests/association.rs`, 19 tests on both roles. `tests/upper.rs`, 17 tests, still pass.
- **Gate**: `porte=1`. `cargo deny` reports the same unused ISC allowance as before.
