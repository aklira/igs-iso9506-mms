# S1 — VMD model

## Prompt

Run task S1 of `IMPLEMENTATION.md`: a typed model of the VMD: domains, named variables, named variable
lists, with access through a trait so that TASE.2 and IEC 61850 can supply their own objects. Read
ISO 9506-1 §7 and §14. Done when the unit and property tests pass.

## Summary

- **Code**: `crates/igs-iso9506-mms/src/vmd/` (`mod.rs` the model, `name.rs` identifiers and targets,
  `variable.rs` the trait and `MemoryVariable`, `conform.rs` the conformance of values to types).
  Public as `igs_iso9506_mms::vmd`.
- **Trait**: `Variable` (type description, writable, read, write). The model checks existence, write
  permission and type before it calls the variable.
- **Lists**: DefineNamedVariableList checks the members at definition; a member removed later fails alone.
- **Decisions**: D-025.
- **Tests**: 25 unit tests in the library (names, conformance per type, variables, the model's own
  behaviour); 12 property tests in `tests/vmd_properties.rs` (identifier lengths, integer and unsigned
  bounds, fixed and maximum sizes, and the model against a reference model over random sequences of
  operations).
- **Not modelled**: named types, unnamed variables, AA-specific names, access control, the other VMD
  classes (`docs/capabilities.md`).
- **Dependency**: `proptest` as a dev-dependency of the client crate, the same as the codec's (MIT or
  Apache-2.0).
- **Gate**: `porte=1` (fmt, clippy, doc, test, msrv 1.85, deny, codegen --check).

## Reading

ISO 9506-1 §7.4 (scopes, lifetime, visibility, deletion), §7.5 (object names), §14.1 (variables, lists,
named types), §14.2.2.4 (simple types and their sizes). ISO 9506-2 §14.12 (the grammar of
DefineNamedVariableList) for the members. No standard text is in the code or the docs: the clauses are
cited, and the rules are written in the project's own words.
