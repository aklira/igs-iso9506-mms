# N7 — Journals: ReadJournal for the log services (task of igs-iso9506-mms, for igs-iec61850-mms Q5)

## Prompt

Phase N of the journals, local (not pushed), for the log services of the IEC 61850 model: the server answers ReadJournal from the
journals of a domain, and the client reads them.

## Summary

- Codegen: ReadJournal in a new scope `iec61850` (`xtask/src/main.rs`); the in-scope flag is read over every row of the tag
  (`xtask/src/emit.rs`); the profile rule of c13 names the feature `Logs` (`xtask/src/profile81.rs`). Regenerated: 14 new types
  (TYPE_COUNT 145 to 159), the service CHOICE of requests and responses, the profile rule of readJournal.
- Codec: `Feature::Logs`, `Model.logs`; `need_service` checks the negotiated service bit for ReadJournal (the parameter check used
  before refused every ReadJournal).
- Server: `vmd/journal.rs`, the journals of a domain, bounded; `Vmd::define_journal`, `append_journal`, `journal`; the handler
  `read_journal` in `server/service.rs` (selection of table 127).
- Client: `Client::read_journal`.
- Tests: `tests/journal.rs` (seven), with the IEC profile that declares logs on both ends; the codec tests of the scope and the type count
  updated. Sibling gate: fmt, clippy (`-D warnings`), 400 tests, `codegen --check`, `cargo deny`.
