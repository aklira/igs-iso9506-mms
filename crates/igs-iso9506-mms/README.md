# igs-iso9506-mms

The async MMS client and server over TCP and TLS, built on `igs-iso9506-mms-link` and `igs-iso9506-mms-codec`: the client has a queue, events, a reconnection policy and a close; the server serves a model of variables and named variable lists.

Part of the `igs-iso9506-mms` workspace. The repository's [README](https://github.com/aklira/igs-iso9506-mms) describes the
architecture, the decisions, and the tests; the [CHANGELOG](https://github.com/aklira/igs-iso9506-mms/blob/main/CHANGELOG.md)
lists each release.
