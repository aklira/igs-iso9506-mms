# igs-iso9506-mms-link

Sans-I/O state machines of the MMS stack: the transport (class 0, RFC 1006), the session and presentation connections, the MMS association with its application context, and the requests with their invoke identifiers, limits, cancel and timeouts. It reads and writes no socket and no clock: the caller gives them.

Part of the `igs-iso9506-mms` workspace. The repository's [README](https://github.com/aklira/igs-iso9506-mms) describes the
architecture, the decisions, and the tests; the [CHANGELOG](https://github.com/aklira/igs-iso9506-mms/blob/main/CHANGELOG.md)
lists each release.
