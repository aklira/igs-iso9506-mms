# igs-iso9506-mms-codec

The MMS codec of ISO 9506 and its ACSE, presentation, session and COTP PDUs: BER, the generated ASN.1 types, and the conformance building blocks that validate a PDU against the negotiated parameters. Sans I/O: it encodes and decodes, and nothing else.

Part of the `igs-iso9506-mms` workspace. The repository's [README](https://github.com/aklira/igs-iso9506-mms) describes the
architecture, the decisions, and the tests; the [CHANGELOG](https://github.com/aklira/igs-iso9506-mms/blob/main/CHANGELOG.md)
lists each release.
